# Design: visual
A chart or diagram with its heading


## Revenue by quarter

In millions of euros.

```@bar
- Q1: 12
- Q2: 18
- Q3: 15
- Q4: 24
```


## A diagram

```@architecture
- Browser (icon: browser)
- API (icon: server)
- Database (icon: database)
- Browser -> API: requests
- API -> Database: queries
```


## Two charts share the slide

```@pie
- Rust: 60
- Go: 25
- Other: 15
```

```@donut
- Done: 70
- Left: 30
```

Text written after a chart stays after it.


## A chart with bullets is content

- The chart and the bullets both show
- In reading order

```@line
- Jan: 3
- Feb: 5
- Mar: 4
- Apr: 8
```
